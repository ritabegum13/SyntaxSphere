SyntaxSphere

Interactive Compiler and Code Analysis System

Project Type: Compiler Construction

Technology: Python, Streamlit

Project Overview

SyntaxSphere is an educational web-based compiler project designed to demonstrate the major phases of compiler construction through an interactive interface.

Objectives

- Perform lexical analysis and token generation.
- Check syntax using grammar rules.
- Perform semantic analysis.
- Maintain a symbol table.
- Generate intermediate code.
- Display compilation errors clearly.

Planned Technologies

- Python
- Streamlit
- Visual Studio Code
